## 📥 如何下載到本機遊玩 (Offline Version)

如果你想要下載到電腦裡離線遊玩：

1. 點擊本頁面右上角的綠色按鈕 **`<> Code`**。
2. 選擇 **`Download ZIP`** 將專案壓縮檔下載到電腦並解壓縮。
3. 確保解壓縮出來的資料夾內同時包含：
   * `index.html`
   * `assets/` (資源資料夾)
4. 直接雙擊滑鼠打開 **`index.html`** 即可在瀏覽器中開始遊戲！
